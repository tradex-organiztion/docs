## 거래소 API

**Q. 여러 거래소를 동시에 연결할 수 있나요?**\
A. 네 가능합니다. 단, Pro 요금제는 한 개의 계정만 지원하며 Premium 요금제부터 여러 계정을 동시에 연동하고 관리할 수 있어요.

**Q. 다른 거래소를 쓰고 있는데 가입을 못하나요?**\
A. 현재 트레이덱스 팀은 더 많은 거래소를 지원하기 위해 활발한 업데이트를 진행하고 있어요. 사용하시는 거래소를 고객센터에 접수해주시면 최대한 빠르게 업데이트하고 개별 연락드릴게요. 신청자가 많은 거래소 순서대로 지원할 예정이니 꼭 접수해주세요.

**Q. 거래소 API 생성 및 연결이 어려워요.**\
A. API 생성 및 연동 과정이 어려우신 경우, 따로 문의주시면 1:1 온보딩을 직접 도와드리고 있으니 카카오톡 혹은 채널톡으로 문의 부탁드립니다.

**Q. API 키가 유출되면 자산이 위험한가요?**\
A. 트레이덱스는 읽기 전용(Read-Only) API만 사용하기 때문에 자산 이동이나 거래가 절대 불가능합니다.

**Q. 거래소 연동 후 매매 데이터가 안 불러와져요.**\
A. API 키 권한이 올바르게 설정되었는지 확인해주세요. 권한은 반드시 **Read-Only**로 설정하고 모든 하위 항목이 선택되어 있어야 합니다. 그래도 문제가 지속되면 고객센터로 문의해 주세요.

## 플랜 및 결제

**Q. 무료 체험 기간이 있나요?**\
A. 신규 가입 시 Premium 플랜을 30일간 제공해 드려요. 현재는 오픈 베타 기간이라 30일 이후에도 무료로 사용 가능합니다.

**Q. 오픈 베타 이벤트는 언제 종료되나요?**\
A. 현재 트레이덱스 오픈 베타 이벤트는 6월 30일 종료 예정이며, 상황에 따라 변경될 수 있습니다.

**Q. 플랜을 중간에 변경할 수 있나요?**\
A. 네, 언제든지 플랜을 업그레이드하거나 다운그레이드할 수 있어요. 업그레이드 시 남은 기간을 일할 계산해 차액만 청구됩니다.

**Q. 환불 가능한가요?**\
A. 트레이덱스는 고객의 사용 여부와 관계없이 계약 기간 동안 제공 가능한 상태로 유지되기 때문에 고객이 결제한 유료 서비스 이용 요금은 원칙적으로 환불되지 않습니다. 다만 예외적으로 환불이 가능한 경우가 있으니, 자세한 내용은 [서비스 이용약관](https://tradex.so/terms)을 참고해 주세요.

**Q. 구독을 취소하면 데이터가 삭제되나요?**\
A. 아니요, 구독 취소 후에도 기록된 매매일지 데이터는 유지됩니다. 추후 다시 구독할 경우, 이전 데이터를 이어서 활용할 수 있어요.

## 계정 및 가입

**Q. 소셜 계정으로 가입하면 기존 이메일 계정과 연동이 되나요?**\
A. 동일한 이메일 주소를 사용하는 소셜 계정으로 가입 시 자동으로 연동됩니다.

**Q. 비밀번호를 잊어버렸어요.**\
A. 로그인 화면의 **비밀번호 찾기**를 클릭해 이메일로 재설정 링크를 받으실 수 있어요.

## 기타

**Q. 거래소 연동 후 매매 데이터가 안 불러와져요.**\
A. API 키 권한이 올바르게 설정되었는지 확인해주세요. 권한은 반드시 **Read-Only**로 설정하고 모든 하위 항목이 선택되어 있어야 합니다. 그래도 문제가 지속되면 고객센터로 문의해 주세요.

**Q. 모바일 앱이 있나요?**\
A. 현재 모바일 앱을 개발 중이며, 출시를 준비하고 있습니다. 추후 공지 예정이니 많은 관심 부탁드립니다.

**Q. 데이터는 얼마나 안전하게 보관되나요?**\
A. 모든 데이터는 암호화되어 안전하게 저장됩니다
