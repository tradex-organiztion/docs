# 자주 묻는 질문

## 자주 묻는 질문

**Q. 여러 거래소를 동시에 연결할 수 있나요?**

A. 네 가능합니다. 단, Pro 요금제는 한 개의 계정만 지원하며 Premium 요금제부터 여러 계정을 동시에 연동하고 관리할 수 있어요.

**Q. 저는 다른 거래소를 쓰고 있어서 가입을 못해요.** 현재 트레이덱스 팀은 더 많은 거래소를 지원하기 위해 활발한 업데이트를 진행하고 있어요. 사용하시는 거래소를 접수해주시면 최대한 빠르게 업데이트하고 개별 연락드릴게요. 신청자가 많은 거래소 순서대로 지원할 예정이니 꼭 접수해주세요.

---

## 계정 & 가입

**Q. 소셜 계정으로 가입하면 기존 이메일 계정과 연동이 되나요?** 동일한 이메일 주소를 사용하는 소셜 계정으로 가입 시 자동으로 연동됩니다.

**Q. 비밀번호를 잊어버렸어요.** 로그인 화면의 **비밀번호 찾기**를 클릭해 이메일로 재설정 링크를 받으실 수 있어요.

**Q. 계정을 삭제하고 싶어요.** 설정 \> 계정 \> 계정 삭제에서 직접 탈퇴하실 수 있습니다. 탈퇴 시 모든 데이터는 즉시 삭제되며 복구가 불가능합니다.

---

## 거래소 연동

**Q. API 키가 유출되면 자산이 위험한가요?** 트레이덱스는 **읽기 전용(Read-Only)** API만 사용합니다. 읽기 전용 API 키로는 자산 이동이나 주문이 절대 불가능해요. 그래도 안전을 위해 API 키는 주기적으로 재발급하는 것을 권장합니다.

**Q. 여러 거래소를 동시에 연동할 수 있나요?** Pro 플랜은 1개 거래소 계정, Premium 플랜은 최대 3개 거래소 계정을 동시에 연동할 수 있어요.

**Q. 거래소 연동 후 데이터가 안 불러와져요.** API 키 권한이 올바르게 설정되었는지 확인해주세요. 권한은 반드시 **Read-Only**로 설정하고 모든 하위 항목이 선택되어 있어야 합니다. 그래도 문제가 지속되면 고객센터로 문의해 주세요.

**Q. 제가 사용하는 거래소가 지원이 안 돼요.** 현재 바이낸스, 바이비트, 비트겟을 지원합니다. 추가 지원을 원하시는 거래소는 고객센터를 통해 접수해주시면 검토 후 업데이트할게요.

## 요금제 & 결제

**Q. 무료로 사용할 수 있나요?** 네, Free 플랜으로 기본 기능을 무료로 사용할 수 있어요. 신규 가입 시 Pro 플랜 7일 무료 체험도 제공됩니다.

**Q. 구독을 취소하면 데이터가 삭제되나요?** 아니요, 구독 취소 후에도 기록된 매매일지 데이터는 유지됩니다. 다만 Free 플랜 기준으로 조회 가능한 기간이 제한됩니다.

**Q. 환불이 가능한가요?** 결제일로부터 7일 이내에 고객센터로 문의하시면 환불 처리해 드립니다.

---

## 기능 문의

**Q. 모바일 앱이 있나요?** 현재 웹 앱으로 운영 중이며, 모바일 브라우저에서도 최적화된 화면으로 이용하실 수 있어요. 네이티브 앱은 준비 중입니다.

**Q. 데이터는 얼마나 안전하게 보관되나요?** 모든 데이터는 암호화되어 안전하게 저장됩니다. API 키는 AES-256 암호화로 보호되며, 서버는 AWS 인프라를 사용합니다.

추가 문의사항은 고객센터로 연락해 주세요.
