# 고급 차트 라이브러리

고급 차트 라이브러리는 TradingView 수준의 전문적인 차트 도구를 트레이덱스 내에서 바로 활용할 수 있는 기능이에요.

---

## 주요 기능

### 멀티 타임프레임 차트
- 1분봉부터 월봉까지 다양한 타임프레임 지원
- 화면을 분할해 여러 타임프레임을 동시에 비교

### 보조 지표 (Indicators)
주요 기술적 분석 지표를 차트에 바로 적용할 수 있어요.

| 카테고리 | 지표 |
|----------|------|
| 추세 | MA, EMA, Bollinger Bands, Ichimoku |
| 모멘텀 | RSI, MACD, Stochastic |
| 거래량 | Volume, OBV, VWAP |
| 변동성 | ATR, Standard Deviation |

### 드로잉 도구
- 추세선, 수평선, 피보나치 되돌림
- 채널, 패턴 표시
- 텍스트 메모 추가

---

## 매매일지와 연동

차트에 내 포지션 진입/종료 지점이 자동으로 표시됩니다.
과거 어떤 시점에 진입하고 청산했는지를 차트에서 직접 확인하고 복기할 수 있어요.

### 복기 모드
특정 매매일지를 선택하면 해당 포지션의 진입·종료 시점이 차트에 마킹됩니다.
당시의 시장 상황을 다시 보며 의사결정을 복기해 보세요.

---

## 차트 저장 & 공유

분석한 차트를 이미지로 저장하거나 매매일지에 첨부할 수 있어요.
