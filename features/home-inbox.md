# 홈 · 수신함

트레이덱스에 로그인하면 가장 먼저 만나는 화면입니다. 내 트레이딩 현황을 한눈에 파악할 수 있어요.

---

## 홈 대시보드

홈 화면에서는 아래 정보를 실시간으로 확인할 수 있어요.

### 오늘의 성과
- 오늘 실현 손익 (PnL)
- 진행 중인 포지션 수
- 승률 (오늘 / 이번 주 / 이번 달)

### 포지션 현황
연동된 거래소의 현재 오픈 포지션을 자동으로 불러옵니다.
- 종목 / 방향 (롱·숏) / 진입가 / 수량 / 현재 손익

### 최근 매매일지
최근에 기록된 매매일지를 빠르게 확인하고 이어서 작성할 수 있어요.

---

## 수신함

수신함은 트레이덱스가 자동으로 생성하는 알림과 인사이트를 모아보는 공간이에요.

### 수신함에서 볼 수 있는 항목

| 유형 | 설명 |
|------|------|
| AI 분석 알림 | Tradex AI가 생성한 전략 피드백 및 인사이트 |
| 매매원칙 위반 경고 | 설정한 원칙에서 벗어난 거래 발생 시 |
| 포지션 변동 알림 | 신규 포지션 진입 또는 종료 시 |
| 주간 성과 리포트 | 매주 월요일 자동 생성 |

### 알림 확인 방법
- 읽지 않은 알림은 빨간 뱃지로 표시됩니다
- 알림을 클릭하면 관련 매매일지나 분석 화면으로 바로 이동해요
