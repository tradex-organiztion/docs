    - 대분류와 중분류로 구분되며 모든 항목을 수정 혹은 삭제하거나 추가할 수 있습니다.
    - 좌측 아이콘을 클릭한 상태로 드래그하면 순서를 변경할 수 있습니다.
    - 모든 항목과 내용을 수정한 뒤 저장하면 템플릿 편집이 완료됩니다.

    - **복기 내용**: 이번 매매에서 잘한 점이나 아쉬운 점, 개선할 점을 자유롭게 입력해 주세요.
    - **매매원칙 준수 여부**: 이번 매매에 해당되거나 지킨 매매원칙에만 체크해 주세요.

## 리스크 점수 판단 기준

트레이덱스는 매매 데이터를 기반으로 리스크 점수를 산출합니다.

### 1. 감정 매매

- **기준:** 전체 거래 중 '감정 매매'로 분류된 거래의 비중

| **단계** | **발생 비율 (%)** |
| :-- | :-- |
| **좋음** | 5% 이하 |
| **양호** | 6% ~ 10% |
| **보통** | 11% ~ 20% |
| **위험** | 21% ~ 34% |
| **심각** | 35% 이상 |

### 2. 계획 외 진입

- **기준:** 사전 시나리오를 작성하지 않은 거래의 비중

| **단계** | **발생 비율 (%)** |
| :-- | :-- |
| **좋음** | 5% 이하 |
| **양호** | 6% ~ 15% |
| **보통** | 16% ~ 29% |
| **위험** | 30% ~ 49% |
| **심각** | 50% 초과 |

### 3. 손절 준수

- **기준:** 설정한 손절가(Stop-loss)를 지키지 않고 홀딩하거나 손절선을 미룬 거래 비중

| **단계** | **미준수 비율 (%)** |
| :-- | :-- |
| **좋음** | 5% 이하 |
| **양호** | 6% ~ 10% |
| **보통** | 11% ~ 20% |
| **위험** | 20% ~ 40% |
| **심각** | 40% 초과 |

### 4. 손익비

| **단계** | **손익비 (Ratio)** |
| :-- | :-- |
| **좋음** | 2.5 이상 |
| **양호** | 1.8 ~ 2.5 |
| **보통** | 1.2 ~ 1.8 |
| **위험** | 0.8 ~ 1.2 |
| **심각** | 0.8 미만 |

## 리스크 패턴 분석이 필요한 이유

수익률만큼 중요한 것이 리스크 관리입니다. 높은 수익률도 한 번의 과도한 손실로 무너질 수 있어요. 트레이덱스는 내 트레이딩 전략의 리스크 패턴을 분석해 지속 가능한 전략을 만들 수 있도록 도와줍니다.
