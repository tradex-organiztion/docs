# Tradex AI

Tradex AI는 내 거래 데이터를 분석해 맞춤형 인사이트와 피드백을 제공하는 트레이딩 전용 AI 에이전트입니다.

---

## Tradex AI가 하는 일

### 1. 매매 패턴 분석
내 거래 이력 전체를 분석해 반복되는 패턴을 발견합니다.
- 어떤 조건에서 수익이 나는지
- 어떤 상황에서 손실이 집중되는지
- 감정적 거래가 발생하는 시간대와 패턴

### 2. 전략 피드백
최근 거래를 분석해 전략 개선 포인트를 제안합니다.

### 3. 시장 분석 지원
차트와 시장 데이터를 기반으로 현재 시장 상황을 해석하는 데 도움을 줍니다.

### 4. 복기 도우미
포지션 종료 후 AI가 해당 거래를 자동으로 분석하고 피드백을 남깁니다.

---

## AI에게 질문하기

트레이덱스 내 어느 화면에서나 AI에게 직접 질문할 수 있어요.

**질문 예시:**
- "지난달 내 손실이 집중된 패턴이 뭐야?"
- "BTC 롱 포지션 진입 시 내 승률은 어때?"
- "이번 주 내 매매에서 개선할 점이 있어?"
- "연속 손실 후 내 다음 거래 승률은 어때?"
