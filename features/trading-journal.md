# 매매일지

매매일지는 트레이덱스의 핵심 기능입니다. 연동된 거래소의 모든 거래를 자동으로 기록하고, 여기에 나만의 메모와 분석을 추가할 수 있어요.

---

## 자동 기록

거래소 API와 연동하면 모든 포지션이 자동으로 매매일지에 기록됩니다.

자동으로 기록되는 정보:
- 종목 (예: BTC/USDT)
- 방향 (롱 / 숏)
- 진입가 / 청산가
- 수량 및 레버리지
- 진입 시간 / 종료 시간
- 실현 손익 (PnL)
- 수수료

---

## 수동 기록 추가

자동 기록 외에 아래 정보를 직접 추가할 수 있어요.

### 진입 근거
- 이 포지션을 잡은 이유를 텍스트로 기록
- 차트 이미지 첨부 가능

### 감정 상태
- 진입 당시 감정 태그 (냉정함 / 확신 / 불안 / FOMO 등)
- 감정과 수익률의 상관관계를 분석하는 데 활용됩니다

### 복기 메모
- 포지션 종료 후 잘한 점 / 아쉬운 점 기록
- AI 자동 피드백과 함께 확인 가능

### 매매원칙 태그
- 이 거래에 적용한 매매원칙 태그 지정
