# 매매원칙

매매원칙은 트레이더 자신만의 규칙을 트레이덱스에 등록해두고, AI가 이를 지키고 있는지 자동으로 모니터링해주는 기능이에요.

---

## 매매원칙이 왜 중요한가요?

성공적인 트레이더의 공통점은 **일관된 매매원칙**을 가지고 있다는 점입니다.
하지만 시장이 급변하거나 감정이 개입될 때 이 원칙을 지키기란 매우 어렵습니다.

트레이덱스는 내가 설정한 원칙에서 벗어난 거래가 발생하면 즉시 알려드립니다.

---

## 매매원칙 등록하기

**핵심 기능 > 매매원칙** 에서 나만의 규칙을 추가할 수 있어요.

### 설정 가능한 원칙 유형

| 유형 | 예시 |
|------|------|
| 최대 손실 한도 | 하루 최대 손실 -3% 이하 |
| 포지션 크기 | 단일 포지션 잔고의 10% 이하 |
| 레버리지 제한 | 최대 10배 이하 |
| 거래 시간 제한 | 오전 9시 ~ 오후 6시 사이에만 거래 |
| 종목 제한 | BTC, ETH만 거래 |
| 연속 손실 규칙 | 연속 3회 손실 시 당일 거래 중단 |

### 등록 방법
1. **매매원칙 > 원칙 추가** 클릭
2. 원칙 유형 선택
3. 조건 값 입력
4. 저장

---

## 원칙 위반 알림

등록된 원칙에서 벗어난 거래가 감지되면:
- 수신함에 위반 알림이 생성됩니다
- 푸시 알림이 발송됩니다 (알림 설정 시)
- 해당 거래에 **원칙 위반** 태그가 자동으로 표시됩니다

---

## 원칙 준수율 확인

매매원칙 화면 상단에서 기간별 원칙 준수율을 확인할 수 있어요.

> 💡 원칙 준수율과 수익률의 상관관계를 분석하면 더 나은 매매 전략을 세울 수 있어요.
