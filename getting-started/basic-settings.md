# 기본 설정

거래소 연동 후 트레이덱스를 더 편리하게 사용하기 위한 기본 설정을 완료해보세요.

---

## 프로필 설정

**설정 > 프로필** 에서 아래 정보를 확인하고 수정할 수 있어요.

- 닉네임
- 프로필 이미지
- 이메일 주소

---

## 알림 설정

트레이덱스는 중요한 시장 이벤트와 내 포지션 변동을 실시간으로 알려드립니다.

**설정 > 알림** 에서 아래 항목을 켜거나 끌 수 있어요.

| 알림 유형 | 설명 |
|-----------|------|
| 포지션 진입/종료 | 연동된 거래소에서 포지션이 변동될 때 |
| AI 분석 완료 | Tradex AI가 분석 결과를 제공할 때 |
| 매매원칙 위반 | 설정한 매매원칙에서 벗어난 거래가 발생할 때 |
| 주간 리포트 | 매주 월요일 지난 주 성과 요약 |

---

## 연동 거래소 관리

**설정 > 거래소 연동** 에서 현재 연동된 거래소를 확인하고 추가·삭제할 수 있어요.

- 연동된 거래소 API 상태 확인
- 새 거래소 추가
- 기존 거래소 API 키 갱신

> 💡 API 키는 주기적으로 재발급하는 것을 권장합니다.
