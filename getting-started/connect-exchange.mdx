## 거래소 별 API 생성 및 연동 방법

<Note>
  트레이덱스는 **읽기 전용(Read-Only)** 권한만 가져오기 때문에 **실제 거래나 계좌에 접근할 수 없어 보안상 안전합니다.**
</Note>

<Warning>
  **IP 화이트리스트 등록을 권장해요.** 거래소에서 API 키에 IP 접근 제한을 설정하는 경우,
  트레이덱스 서버 IP **`3.36.183.125`** 를 반드시 등록해야 연동이 유지돼요.
  바이비트는 IP 제한이 없는 키를 90일 후 자동 만료시켜요. IP 를 등록해 두면 만료 없이 유지돼요.
</Warning>

  <Tab title="바이낸스">
    ## 바이낸스

    바이낸스 계정 연동을 위해서는 **API Key**, **API Secret** 두 가지 정보가 필요해요.

    <Frame>
      ![\[바이낸스\]1](/images/[바이낸스]1.png)
    </Frame>

    1. 바이낸스 로그인 후 우측 상단 프로필에서 **Account** 페이지를 클릭해 주세요.

    <Frame>
      ![\[바이낸스\]2](/images/[바이낸스]2.png)
    </Frame>

    2. **API Management** 페이지 우측 상단에서 **Create API** 버튼을 클릭해 주세요.

    <Frame>
      ![\[바이낸스\]3](/images/[바이낸스]3.png)
    </Frame>

    3. API 유형에서 상단의 **System generated**를 선택해 주세요.

    <Frame>
      ![\[바이낸스\[4](/images/[바이낸스[4.png)
    </Frame>

    4. API 이름을 자유롭게 입력하고 인증을 완료해 주세요.

    <Frame>
      ![\[바이낸스\]5](/images/[바이낸스]5.png)
    </Frame>

    5. **Enable Reading** 항목 옆의 **Enable Futures** 항목도 함께 체크해 주세요. (사진은 예시이며, Futures 는 별도로 켜야 해요.) 선물 권한이 없으면 연동에 실패할 수 있어요.
    6. **API Key**와 **Secret Key**를 복사 및 기록하고 트레이덱스에서 거래소 연동 시 입력해 주세요.

    <Danger>
      **Secret Key는 최초 생성 시에만 확인 가능하니 반드시 저장해 주세요.**<br />(만약 키를 분실했다면, 재생성 후 다시 연동해 주세요.)
    </Danger>
  </Tab>
  <Tab title="바이비트">
    ## 바이비트

    바이비트 계정 연동을 위해서는 **API Key**, **API Secret** 두 가지 정보가 필요해요.

    <Frame>
      ![\[바이비트\]1](/images/[바이비트]1.png)
    </Frame>

    1. 바이비트 로그인 후 우측 상단 프로필에서 **API**를 클릭해 주세요.

    <Frame>
      ![\[바이비트\]2 1](/images/[바이비트]2-1.png)
    </Frame>

    2. **API Management** 페이지 우측 상단에서 **Create New Key** 버튼을 클릭해 주세요.

    <Frame>
      ![\[바이비트\]3](/images/[바이비트]3.png)
    </Frame>

    3. API 유형에서 상단의 **System-generated API Keys**를 선택해 주세요.

    <Frame>
      ![\[바이비트\]4](/images/[바이비트]4.png)
    </Frame>

    4. **API Transaction** 항목을 선택해 주세요.
    5. API 이름을 자유롭게 입력해 주세요.
    6. 권한 설정에서 **Read-Only** 항목을 선택해 주세요. IP 제한을 사용하려면 트레이덱스 서버 IP(**3.36.183.125**)를 등록해 주세요. IP 제한이 없는 키는 90일 후 자동 만료되니 등록을 권장해요.

    <Frame>
      ![\[바이비트\]6](/images/[바이비트]6.png)
    </Frame>

    7. 사진과 동일하게 전체 항목을 체크해 주세요.
    8. 제출 후 인증을 완료하면 API 생성이 완료됩니다.
    9. **API Key**와 **Secret Key**를 복사 및 기록하고 트레이덱스에서 거래소 연동 시 입력해 주세요.

    <Danger>
      **Secret Key는 최초 생성 시에만 확인 가능하니 반드시 저장해 주세요.**<br />(만약 키를 분실했다면, 재생성 후 다시 연동해 주세요.)
    </Danger>
  </Tab>

    ## 비트겟

    비트겟 계정 연동을 위해서는 **API Key**, **API Secret**, **Passphrase** 세 가지 정보가 필요해요.

    <Frame>
      ![\[비트겟\]1](/images/[비트겟]1.png)
    </Frame>

    1. 비트겟 로그인 후 우측 상단 프로필에서 **API Keys**를 클릭해 주세요.

    <Frame>
      ![\[비트겟\]2 1](/images/[비트겟]2-1.png)
    </Frame>

    2. **API Keys** 페이지 우측 상단에서 **Create New Key** 버튼을 클릭해 주세요.

    <Frame>
      ![\[비트겟\]3](/images/[비트겟]3.png)
    </Frame>

    3. API 유형에서 상단의 **System-generated API Key**를 선택해 주세요.

    <Frame>
      ![\[비트겟\]4](/images/[비트겟]4.png)
    </Frame>

    4. API 이름을 자유롭게 입력해 주세요.
    5. 권한 설정에서 **Read-Only** 항목과 **Select all**을 선택해 모든 항목을 선택해 주세요.
    6. **Bind IP Addresses** 항목에 트레이덱스 서버 IP(**3.36.183.125**) 등록을 권장해요. (비워둬도 연동은 되지만 키 관리상 등록이 안전해요)
    7. 제출 후 인증을 완료하면 API 생성이 완료됩니다.
    8. **API Key**와 **Secret Key**를 복사 및 기록하고 트레이덱스에서 거래소 연동 시 입력해 주세요.

    <Danger>
      **Secret Key는 최초 생성 시에만 확인 가능하니 반드시 저장해 주세요.**<br />(만약 키를 분실했다면, 재생성 후 다시 연동해 주세요.)
    </Danger>

    ## OKX

    OKX 계정 연동을 위해서는 **API Key**, **API Secret**, **Passphrase** 세 가지 정보가 필요해요.

    <Frame>
      ![\[바이비트\] 1](/images/[바이비트]-1.png)
    </Frame>

    1. OKX 로그인 후 **우측 상단 프로필**을 클릭해 주세요.

    <Frame>
      ![\[바이비트\] 6](/images/[바이비트]-6.png)
    </Frame>

    2. **API and connections** 페이지를 클릭해 주세요.

    <Frame>
      ![\[바이비트\] 7](/images/[바이비트]-7.png)
    </Frame>

    3. 우측 상단에서 **Create New Key** 버튼을 클릭해 주세요.

    <Frame>
      ![\[바이비트\] 9](/images/[바이비트]-9.png)
    </Frame>

    4. API 이름을 자유롭게 입력해 주세요.
    5. **Permissions** 설정에서 **Read** 항목을 선택해 주세요.
    6. **Trusted IP access** 항목에 트레이덱스 서버 IP(**3.36.183.125**) 등록을 권장해요. 등록해 두면 키가 다른 곳에서 쓰이는 것을 막을 수 있어요. (비워둬도 연동은 돼요)
    7. **Passphrase** 항목을 자주 사용하시는 비밀번호로 입력 후 기록해 주세요.
    8. 제출 후 인증을 완료하면 API 생성이 완료됩니다.
    9. **API Key**와 **Secret Key**, **Passphrase**를 복사 및 기록하고 트레이덱스에서 거래소 연동 시 입력해 주세요.

    <Danger>
      **Secret Key는 최초 생성 시에만 확인 가능하니 반드시 저장해 주세요.**<br />(만약 키를 분실했다면, 재생성 후 다시 연동해 주세요.)
    </Danger>
  </Tab>
