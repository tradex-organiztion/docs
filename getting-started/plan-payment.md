# 플랜 결제

트레이덱스는 무료 체험 후 유료 플랜으로 전환할 수 있어요.

---

## 요금제 비교

| | Free | Pro | Premium |
|---|---|---|---|
| 거래소 연동 | 1개 | 1개 | 3개 |
| 매매일지 | 최근 30일 | 전체 | 전체 |
| AI 분석 | 제한 | 월 50회 | 무제한 |
| 전략 분석 | 기본 | 상세 | 상세 + 맞춤 |
| 리스크 분석 | - | ✓ | ✓ |
| 고급 차트 | - | ✓ | ✓ |
| 수익 관리 | - | ✓ | ✓ |
| 우선 지원 | - | - | ✓ |

---

## 결제 방법

**설정 > 요금제** 에서 원하는 플랜을 선택하고 결제할 수 있어요.

지원 결제 수단:
- 신용카드 / 체크카드
- 해외 카드 (Visa, Mastercard)

결제는 매월 자동으로 갱신되며, 언제든 해지할 수 있어요.

---

## 자주 묻는 질문

**Q. 무료 체험 기간이 있나요?**
신규 가입 시 Pro 플랜을 7일간 무료로 체험할 수 있어요.

**Q. 플랜을 중간에 변경할 수 있나요?**
네, 언제든지 플랜을 업그레이드하거나 다운그레이드할 수 있어요.
업그레이드 시 남은 기간을 일할 계산해 차액만 청구됩니다.

**Q. 환불 정책은 어떻게 되나요?**
결제일로부터 7일 이내에 고객센터로 문의하시면 환불 처리해드립니다.
